# Window Annotator

给**任意 Windows 窗口**贴手绘标注——画笔、手绘箭头、荧光笔、手写便签。
标注跟着窗口走:窗口移动、缩放,标注跟着动;**页面上下滚动,标注跟着滚**;
窗口最小化或切到后台,标注自动隐藏;窗口关掉再打开,标注自动恢复。

灵感来自朋友的 Obsidian 插件 Crisp Annotations(手绘箭头+手写笔记的视觉语言),
本项目把这种「随手标注」从单个软件扩展到整个系统。代码全部独立实现。

## 用法

双击 `启动 Window Annotator.vbs`(或命令行 `npm start`)。
**程序必须在运行中,快捷键才有效**——启动后右下角托盘会出现红色 ✎ 图标,并弹通知告知当前快捷键。

如果 `Ctrl+Alt+A` 被其他软件占用(QQ 截图的默认键正是它),程序会自动改用
`Ctrl+Alt+W`,再不行 `Ctrl+Shift+Alt+A`,实际用哪个以启动通知/托盘提示为准。

| 操作 | 效果 |
|---|---|
| `Ctrl+Alt+A` | 给**当前窗口**贴上标注层并进入标注模式;再按一次退出标注模式 |
| `Esc` / 工具条「完成」 | 退出标注模式,回到正常使用(鼠标穿透,标注仍显示) |
| 右下角 ✎ 小按钮 | 查看模式下悬停点击,重新进入标注模式 |
| `Ctrl+Z` | 标注模式下撤销 |
| `Ctrl+Alt+Q` | 退出整个程序 |

工具条:画笔 / 箭头 / 荧光笔 / 手写便签 / 橡皮 + 6 色。

**手写便签怎么用**:点工具条的 `Aa` → 光标变成文字光标 → 在页面上**点一下**,原地出现一个虚线输入框 → 直接打字 → 打完点别处、按 `Esc` 或 `Ctrl+Enter` 收起。已有便签:标注模式下**拖动**可移位,**双击**可改字,选橡皮点它可删。

**托盘右键菜单**:开机自动启动(开关)、滚动跟随灵敏度(慢/正常/快)、打开存档文件夹、退出。

## 原理(三层)

1. **Win32 桥**(`src/win32.js`,koffi FFI 免编译):拿窗口精确可见边框
   (DWM extended frame bounds)、前台/最小化/隐身状态、进程名。
2. **追踪循环**(`main.js`):每 16ms 对齐一次覆盖层;目标窗口在前台才显示覆盖层,
   借此绕开「置顶层盖住别的窗口」的 z-order 难题。
3. **标注画布**(`overlay/`):透明覆盖窗口,查看模式整窗鼠标穿透
   (`setIgnoreMouseEvents + forward`),标注模式接管鼠标。手绘感 = 种子化随机抖动
   (每个标注存 seed,重画不变形);手写体用 Windows 自带 Ink Free / Segoe Print,零版权负担。
4. **跟随滚动**:外挂浮层读不到目标软件内部的滚动位置,所以用 `WH_MOUSE_LL` 低级鼠标钩子
   在系统层截下滚轮增量,按帧换算成像素、整体平移标注(标注坐标存"内容坐标"= 滚动=0 时的
   窗口坐标)。方向精确;幅度是估算的(滚一格默认 100px,托盘可调慢/正常/快),因为不同软件
   的滚动步长不一样,做不到像素级同步。

## 存档

`data/annotations.json`,键为 `程序名|窗口标题`。设置(滚动灵敏度)存 `data/settings.json`。
开机自启交给系统登录项(注册表 Run 键),不自己记状态。

## 已知边界(MVP)

- 跟随滚动是"估算量":滚动方向准,但滚动**幅度**因软件而异(托盘可调三档灵敏度找手感)
- 标注跟窗口左上角走,窗口**缩放**时标注不缩放(相对内容会错位;跟随移动/滚动没问题)
- 目标窗口不在前台时标注隐藏(这是特性,也是 z-order 的取舍);离开期间目标若滚动过,回来会有偏移
- 窗口标题变化(如浏览器切换标签页)会被视为另一个窗口的存档键
